# 恶意软件 API 调用序列分类与对抗训练

基于 API 调用序列的恶意软件分类研究项目，支持多种深度学习模型架构、可插拔注意力机制模块以及隐空间对抗训练 (Latent Adversarial Training)。

## 项目结构

```
qz_dl/
├── src/
│   ├── configs/       # 实验配置 (模型、数据集、训练超参)
│   ├── models/        # 模型架构: LSTM, TCN, Conv1D, Conv2D, BERT
│   │   └── pluggable/ # 可插拔模块 (自注意力、位置编码、MLP注意力等)
│   ├── datasets/      # 数据集加载与预处理
│   │   └── instances/ # 各数据集具体实现
│   ├── light/         # 训练器 (标准训练、对抗训练、AWP、多标签)
│   │   └── loss_box/  # 自定义损失函数
│   ├── evaluation/    # 评估指标 (准确率、F1等)
│   ├── schemas/       # Pydantic 实验配置模式定义
│   └── utils/         # 工具函数 (日志、CUDA、文本预处理等)
├── scripts/           # 训练/攻击脚本集合
├── train_*.py         # 各实验入口脚本
└── requirements.txt   # 依赖 (PyTorch, transformers, gensim 等)
```

## 支持的模型

| 模型             | 描述                                          |
| ---------------- | --------------------------------------------- |
| **BiLSTM**   | 基于 LSTM 的序列分类器                        |
| **TCN**    | 时序卷积网络 (Temporal Convolutional Network) |
| **TextCNN** | 一维卷积文本分类器                            |

## 可插拔模块

每个模型均可选配以下注意力/增强模块（通过 `PluginType` 配置）：

- **Self-Attention** — 自注意力机制
- **Positional Encoding** — 位置编码
- **Self-Attention + PE** — 自注意力 + 位置编码
- **MLP Attention** — MLP 注意力机制
- **Gaussian Noise** — 高斯噪声注入
- **Identity** — 恒等映射 (无增强)

## 支持的数据集

| 数据集                   | 任务类型     | 类别数 | 来源                                    |
| ------------------------ | ------------ | ------ | --------------------------------------- |
| MalAPI2019               | 单标签多分类 | 8      | API call sequences                      |
| Malware Analysis         | 二分类       | 2      | Kaggle                                  |
| Dynamic Malware Analysis | 多标签分类   | 15     | API calls generated by dynamic analysis |

## 对抗训练

项目实现了**隐空间 PGD 对抗训练 (Latent PGD / Free-AT)**，在 Embedding 层面添加扰动并联合优化：

- **PGD** — Projected Gradient Descent 攻击
- **FGM** — Fast Gradient Method 攻击
- **Free-AT** — 在每个 batch 内同时更新扰动和模型参数

主要依赖 PyTorch，具体版本见 `requirements.txt`。
